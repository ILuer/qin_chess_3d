# 秦风 · 3D 中国象棋

纯前端 3D 中国象棋。**无后端、无构建步骤、无外部资源文件** —— 所有 3D 模型程序化建模，所有贴图 Canvas 运行时绘制，所有音效 WebAudio 实时合成。

美术风格统一为秦朝特色：玄黑与赤红配色、秦式甲胄、青铜兵器与云雷纹旗帜。七种棋子各自独立建模为人物 / 器物形象，而非平面圆片。

---

## 快速开始

项目使用原生 ES Modules，**必须通过 HTTP 访问**（`file://` 协议会被浏览器 CORS 策略拦截）。

```bash
# 方式一：用附带的零依赖服务器（推荐）
node serve.mjs
# → http://localhost:5173

# 方式二：任意静态服务器
npx serve .
python -m http.server 5173
```

首次加载需从 CDN 拉取 Three.js（约 600KB），之后走浏览器缓存。

**要求**：支持 WebGL2 的现代桌面浏览器（Chrome / Edge 110+、Firefox 110+、Safari 16+）。

## 坐标系约定

所有模块共享同一套坐标契约（定义于 `src/core/constants.js`）：

```
file: 0..8   列，红方视角从左到右
rank: 0..9   行，rank 0 = 黑方底线，rank 9 = 红方底线

worldX = (file - 4) * 1.0        →  -4 .. +4
worldZ = (rank - 4.5) * 1.0      →  -4.5 .. +4.5
棋盘台面顶部 y = 0，棋子沿 +Y 生长
河界位于 worldZ = 0
```

## 操作

| 输入 | 行为 |
|------|------|
| 左键点击己方棋子 | 选中，显示全部合法落点 |
| 左键点击落点 | 走子 |
| 左键点击己方另一子 | 直接切换选中（无需先取消） |
| 左键拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| `R` | 复位视角 |
| `F` | 翻转视角（红/黑方） |
| `Space` | 俯视 / 斜视切换 |
| `U` / `Ctrl+Z` | 悔棋 |
| `M` | 静音开关 |
| `?` | 规则速查面板 |
| `Esc` | 取消选择 |

## 设计原则落地

- **Juice（果汁）** — 一次输入换大量正向反馈：选中光环旋转 + 棋子悬浮、落子挤压回弹 + 粒子迸发 + 音效微随机化、吃子冲刺 + 碎裂消散 + 分级震屏、将军全屏红脉冲。
- **Oil（润滑油）** — 消除操作摩擦：单击走子而非拖拽、切换选中无需取消、非法点击不清空选择、悔棋一键、视角一键复位、偏好本地持久化。
- **Windex（玻璃清洁剂）** — 规则一目了然：空点与可吃点视觉区分、蹩马腿/塞象眼阻挡点显示叉号、非法走法给出**具体中文原因**而非笼统拒绝、上一步走子持续标记、折叠式规则速查。

详见 `docs/juice-oil-windex.md`（含逐条验收标准）。
