# GDD · UI 交互系统 (ui)

## 1. 概述
指针事件驱动的交互层：选中 / 落子 / 提示 / 记录 / 控件 / 快捷键 / 移动端触控，贯彻 Oil（零摩擦）与 Windex（可视化反馈）原则。

## 2. 目标
让玩家无需学习即可完成「看 → 选 → 走」，所有合法性与威胁即时可读。

## 3. 核心循环
指针按下 → `handleClick` 状态机（选 / 切换 / 走 / 拒 / 取消）→ 驱动 `gameState.move` → `effects` 提示 → `hud` 同步。

## 4. 机制
- Oil：单击选中 / 落子，无拖拽；`DRAG_THRESHOLD=5px` 超阈值判转视角不触发点击。
- 状态机：再点同子取消 / 点己方另一子切换 / 合法落点走子 / 非法目标拒绝但保留选择 / 点外取消。
- Windex：合法落点 = 呼吸光盘；可吃 = 红危险环 + 十字准星；阻挡 = 灰叉；将军 = 红脉冲横幅。
- 拾取：`raycaster` 的 `pickPiece` / `pickCell`；每帧悬停射线更新。

## 5. 数值
确认窗口 `CONFIRM_WINDOW=3200ms`（重开 / 认输二次确认）；快捷键 R 复位视角 / F 翻转 / Space 俯视 / U·Ctrl+Z 悔棋 / M 静音 / N 重开 / ? 帮助 / Esc 取消选择。

## 6. 边界与异常
- 动画 `isBusy` 期间忽略点击，避免重复落子。
- 移动端触控经 Pointer Events 统一处理，无需单独分支。
- 非法着法 → `rules.explainIllegal` toast，选择保留。

## 7. 跨系统依赖
- 依赖：`rules`（合法性 / 阻挡）、`gameState`（状态 / 记谱）、`effects`（提示）、`audio`（点击音）。
- 被依赖：`main`（控件回调）、`render`（射线坐标）。

## 8. 开放问题
- 无键盘无障碍导航（仅靠鼠标 / 触控拾取）。
- 移动端小屏 HUD 拥挤，未做响应式重排。
