# 秦风 3D 中国象棋 · 概念文档

## MDA 框架
- **机制 Mechanics**：9×10 棋盘、七子规则、将军 / 将死 / 困毙判负、中文纵线记谱、悔棋、认输、和棋（光将 / 半回合超限 / 协议）。
- **动态 Dynamics**：单击选中 → 走子 → AI 回合泵轮询回应；合法落点呼吸光点、可吃红环、阻挡灰叉、将军红脉冲构成即时可读的反馈闭环。
- **美学 Aesthetics**：秦风沉浸式 3D 对弈——玄黑 / 赤红 / 青铜 / 鎏金程序化美术，Juice 特效（抛物线落子、回弹、粒子、涟漪、屏震）带来「落子有声、攻防有形」的礼仪感。

## 设计支柱
1. **规则即真相**：规则引擎为唯一权威，UI / AI / 动画皆从逻辑状态派生，零状态分叉。
2. **零摩擦操作**：Oil 单击交互，无拖拽；Windex 可视化一切合法性，降低认知负荷。
3. **本地优先、零依赖**：纯前端零构建、零外部资源，单目录可部署；Worker 优先、主线程降级保可用。

## 视觉锚点
秦式配色（玄黑 xuanHei / 赤红 chiHong / 青铜 qingTong / 鎏金 liuJin），程序化 Canvas2D 贴图，七子为可辨识 3D 人物 / 器物。

## 范围分层
- **Must**：完整规则 + AI + 渲染 + 人机对弈 + 基础音效 + 悔棋 / 认输 / 和棋。
- **Should**：分兵种差异化音效与动画、视角预设、移动端触控。
- **Could**：联机对战、残局库、谱库回放、无障碍增强。

## 目标玩家（Bartle）
成就型（挑战 AI 三档难度）/ 探索型（理解走法与记谱）/ 社交型（与人对弈、分享棋谱）。

## 心流与自决论
- **自主**：玩家选先手方、难度、视角、节奏（悔棋 / 认输自主）。
- **胜任**：Windex 提示降低入门门槛，AI 难度梯度提供成长曲线。
- **关联**：吃子陈列、走子记录、将军横幅强化对弈「对手感」。
