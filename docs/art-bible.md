## 1. 品牌基调与秦风世界观锚点

- **一句话定调**：不是"木头棋子摆在木头棋盘上"，而是**两支秦军在夯土校场上列阵对垒**。棋子是人与器，不是刻字的圆柱。
- **朝代锚点**：秦。尚黑、水德、青铜文明晚期。装饰母题固定为**云雷纹（方形回旋）**，由 `createLeiWenTexture()` 程序化生成，用在底座侧面与旗面边框——全项目唯一的纹样语言，不再引入第二套花纹。
- **气氛锚点**：夜战校场。深色环境 + 四角青铜灯柱火光 + 秦军"秦"字旗，主体靠光雕出来，不靠亮底衬出来。
- **技术信条（对美术是硬约束）**：**100% 程序化、零外部资源**。没有 `.png` / `.glb` / `.ttf`，所有贴图由 Canvas2D 在运行时绘制成 `CanvasTexture`，所有形体由 Three.js 内置几何体组合。任何"找张贴图贴上去"的方案在本项目一律不成立。
- **红黑区分原则**：**形制完全相同，材质与配色不同**（`materials.js` 开篇契约）。红方＝赤红戎装＋鎏金/青铜配件＋暖调；黑方＝玄黑甲胄＋冷银/暗铜配件＋冷调。绝不用"红方是骑兵、黑方是步兵"这种形体区分。
- **克制线**：写意 > 考据。剪影可辨 > 细节堆砌。任何细节若在默认视角（`phi≈0.64`，距离 13.6）看不清，就不该存在。

## 3. 材质与表面

全部使用 `MeshStandardMaterial`。**PBR 数值分档（`materials.js` 已固化，新增资产必须落入此表）**：

| 材质档 | roughness | metalness | 典型用处 |
|---|---|---|---|
| 布料 | 0.85 | 0.00 | 戎装、袍身、鞍 |
| 皮革 | 0.72 | 0.05 | 革带、战靴、马皮（借用）、盾 |
| 甲片 | 0.35 | 0.85 | 筒袖铠、鱼鳞甲、披膊 |
| 兵刃 | 0.28 | 0.92 | 剑身、戈援 |
| 木构 | 0.70 | 0.05 | 战车、抛石机、旗杆、棋盘 |
| 玉石 | 0.25 | 0.00 | 玉饰 |
| 鎏金 | 0.30 | 0.95 | 底座顶沿环、外框角、装饰 |

- **贴图三件套**（全部程序化）：`createLeiWenTexture` 云雷纹饰带、`createWoodTexture` 年轮木纹（含暗角 vignette）、`createTextTexture` 透明底汉字。三者末尾都叠 **±16~22 的像素噪点**——这是本项目"去塑料感"的统一手法，新增贴图必须照做。
- **底座顶面字自发光**（`getBaseTopMaterial`）：同一张贴图兼作 `emissiveMap`，`emissiveIntensity = 0.28`。斜俯视角下顶面必落入自身阴影，纯外部布光救不回来；**强度上限硬性 0.30**，再高鎏金字面会在主光直射下过曝发白。
- **自发光只给三处**：底座字面（0.28）、火焰（`emissiveIntensity` 2.1~2.55 呼吸）、棋盘界线（`#3a2f18` @ 0.6）。其余一律 0。
- FX 高亮统一用 `MeshBasicMaterial` + `transparent` + `depthWrite:false`，不参与光照。

## 4. 棋子形象语言

**核心原则：七种棋子＝七个可辨识的立体形象，剪影互不雷同。禁止"圆柱刻字"。**
汉字只作为**底座顶面的身份标识**（绘于半径 0.55R~0.95R 的外圈环带，中心留给人物立台，双向各绘一次供两侧玩家正读），不是主体。

| 类型 | 形象 | 剪影记忆点 | 标称顶高 `PIECE_TOP_Y` |
|---|---|---|---|
| `P` 兵/卒 | 秦步兵 | 最矮小、介帻软帽、持戈＋小圆盾 | 0.79 |
| `A` 士/仕 | 宫廷卫士 | **笔直对称**、筒袖铠、双手拄剑于身前 | 0.88 |
| `B` 象/相 | 书生 | **无兵器**、宽袖深衣外扩、进贤冠、双手捧简牍 | 0.88 |
| `N` 马 | 骑兵 | 人骑马上、前腿抬起、长戟斜指 | 0.95 |
| `C` 炮 | 抛石车 | A 字木架＋抛杆斜指前方＋配重箱＋两名操作兵 | 1.02 |
| `R` 车 | 双马战车 | 双马并排（前后错落）＋车舆＋御马兵＋持戈兵＋车旗 | 1.08 |
| `K` 将/帅 | 主帅端坐龙椅 | **唯一坐姿**、鹖冠立缨双羽、帅旗、最高 | 1.12 |

- **朝向契约**：构建期一律朝 `-Z`；黑方由 `orient` 层整体绕 Y 旋转 180°。所有兵器、面部、旗面朝向都靠这条统一。
- **尺寸基准**：`PIECE_BASE_RADIUS 0.40`，底座高 `BASE_H 0.06`，人物起始高 `FOOT 0.086`，格距 `GRID 1.0`。
- **分组契约**（阶段三动画依赖，改形体时不可破坏）：`root > orient > {...}`。K＝`body`/`throne`；C＝`trebuchet`/`soldierL`/`soldierR`；R＝`horses`/`body`/`driver`/`spearman`；P/N/B/A 为单组。
- **性能手法**：每枚棋子 28~45 个几何零件，构建期按材质 `mergeGeometries` 合并为 4~8 个 Mesh，32 枚棋子 draw call 从 ~1200 压到 ~180。**新增细节必须能并进已有材质桶**，否则就是净增 draw call。

## 5. 棋盘 / 河界 / 环境

**棋盘（`createBoard()`）—— 台面顶部恰好 `y = 0`，这是全项目的地平面契约。**

- 台面：`9.70 × 10.70 × 0.32` 木板，顶面用 `woodTop` 贴图、四侧用 `woodEdge`。落子区半宽 4.0（file）/ 半深 4.5（rank）。
- 界线：**全部合并为 1 个 Mesh**。线厚 0.012、中心高 0.005；普通线宽 0.026，外框线 0.042，装饰内框 0.018。竖线中间 7 条在河界处中断（`|z| < 0.5`）。
- 位标：传统"十"字直角标，臂长 0.20、间隙 0.095，标在四个炮位与十个兵/卒位。
- 河界：`|z| ≤ 0.5` 暗色微浮雕嵌板 + 两侧金色水波细线；`楚河`（x = −1.95）/`漢界`（x = +1.95）为透明底文字面片，`renderOrder = 2`，字体栈 `STKaiti / KaiTi / STSong / SimSun / Songti SC`。
- 外框：朱漆框（宽 0.35、高 0.055）+ 四角鎏金块。

**环境（`createEnvironment()`）—— 铁律：装饰物只许在 `|x| > 5.6` 或 `|z| > 6.0`，且高度受控，不得遮挡棋盘与相机轨道。**

- 雾化圆形地面（半径 34，`y = −0.90`）+ 深色石质地台（`11.9 × 0.56 × 12.9`）+ 鎏金压边。
- 四角青铜灯柱（`±6.35, ±6.85`）：础/柱/箍/灯盘＋独立火焰锥。火焰由 `userData.update(t)` 驱动呼吸：双正弦 scale 抖动 + `emissiveIntensity` 在 2.1±0.45 波动。
- 秦军旗帜 ×4（红方 `z = +3.60`，黑方 `z = −3.60`，各左右两面）：旗面 PlaneGeometry 顶点位移做出布料起伏，旗面绘"秦"字＋云雷边框，`rotation.y` 自动正对棋盘中心。

> 说明：scene.js 的每一处偏离在代码注释里都写明了动机（"任意视角下清晰可辨""避免鎏金打爆""纯黑背景下玄黑棋子糊进背景"），**均为可读性驱动的合理调整**。因此 CONCERN-1 的建议方向是**把 LIGHT_PRESET 更新为 scene.js 的实测值**，而不是把 scene.js 回退。

## 7. 排版与 UI 视觉基调

- **设计令牌唯一源**：`styles/main.css` 的 `:root`，与 `constants.js` 的 `PALETTE.CSS` 一一对应。`index.html` 内联的 `--qin-bg #0a0b0e` / `--qin-ink #e6dcc3` / `--qin-gold #c9a227` 是**首屏兜底**（防 CSS 未就绪白屏），不是第二套主题——新增变量一律加在 `main.css`，不要往内联块里加。
- **字体栈（零外部字体）**：UI `--font-ui` = system-ui → PingFang SC → Microsoft YaHei → Noto Sans CJK SC；数字/等宽 `--font-num` = SF Mono → ui-monospace → Consolas。3D 内汉字另用楷/宋栈（见第 5 节）。
- **文字层级**：`--text #e8e3d6`（正文）→ `--text-dim #9a958a`（次要）→ `--text-faint #6b6760`（弱化）。基准 14px / line-height 1.5。
- **面板语言**：`--panel-bg rgba(16,17,21,.86)` + `--panel-border rgba(201,162,39,.42)` 鎏金细描边 + 圆角 `--r-md 10px` + `--shadow-2`。所有浮动面板（HUD / 走子记录 / 控制栏 / 帮助抽屉 / toast）共用这一套，无例外。
- **秦式字距**：标题类一律拉字距——加载标题 `.3em`、将军横幅 `.4em`、结束标题 `.2em`。这是本项目最省成本的"古意"手段。
- **强调色分工**：鎏金＝可交互/标题；`--check #ff2b1d`＝将军与危险；`--ok #6fd6a8`＝成功。按钮基态 `rgba(201,162,39,.14)`，hover `.28`，active `translateY(1px)`。
- **过渡**：统一 `--ease cubic-bezier(.22,.61,.36,1)`，时长 0.15~0.3s。

## 8. 动效 / Juice 语言

**时间常量唯一源：`constants.js` → `TIMING`（单位秒）。任何动效时长不得硬编码，一律引用此表。**

| 键 | 值 | 含义 |
|---|---|---|
| `moveDuration` | 0.38 | 普通移动 |
| `captureLunge` / `strikeRecoil` | 0.12 / 0.18 | 吃子冲刺 / 斩杀回弹 |
| `captureDissolve` | 0.42 | 被吃方消散 |
| `liftHeight` | 0.85 | 抛物线弧顶高度 |
| `squashDuration` | 0.16 | 落子回弹（回弹段 ×2.2） |
| `hintFade` / `viewTween` / `toastLife` | 0.18 / 0.75 / 3.0 | 提示淡出 / 视角插值 / toast |

- **落子回弹（squash & stretch）**：默认强度 0.22 —— 压扁 `y×(1−0.22)`、横向 `×(1+0.176)`，再以 2.2 倍时长回弹。开局落子用 0.18。
- **分兵种移动风味**（`MOVE_FLAVOR` 的 `liftMul`，乘在 `liftHeight` 上）：马 1.45（骑兵腾跃）、象 1.35（飞身滑翔）、车 1.05、炮/帅 1.00、士 0.96、兵 0.92（低伏前压）。马额外插一个中点 waypoint，走出"走日"的两段跳。
- **炮的特例**：炮吃子不走滑动，走「抛石命中 → 目标原位消散 → 攻方警戒复位」的专属分支。
- **粒子**：落子 42 颗、吃子 60 颗；颜色吃子用 `chiHong`、平移用 `liuJin`；附带一圈 `liuJinLight` 涟漪环（`RingGeometry 0.3~0.36`，life 0.6s）。
- **震屏**（`intensity, duration`）：吃子 `0.06, 0.26`；将军 `0.12, 0.30`；将死 0.22。多次触发取较强的一次，不叠加。衰减 `k²`。
- **待机微动**（`tickIdle`，每帧全员）：全体极轻呼吸 `y = sin(1.15t+φ)×0.012` + 摇摆 `rot.z = sin(0.85t+φ)×0.014`；炮的两名士兵推车摆动 ±0.12、抛石机咯吱 ±0.02；车的战马微跳 0.03、御马兵/持戈兵晃动 ±0.05。移动中 `_busy = true` 时**只归零 orient，绝不触碰子组**（会与补间打架穿模）。
- **悬停/拒绝**：悬停浮起 0.12~0.16（0.14~0.18s）；非法着法 `shakeMesh(0.12, 0.3)` 明确拒绝。
- **提示几何**（形状即语义，见第 9 节）：可走点＝小实心盘 `r 0.17` + 细环 `0.20~0.235`；可吃点＝**大红环** `0.36~0.45`；选中＝盘 `r 0.44`；将军＝双环 `0.44~0.62` + `0.66~0.72`。

## 9. 可访问性基础

**当前分级：Standard（部分达标）。** 已达成项与缺口如下，UX 规格应引用本节。

**已达成**

- **提示语义双编码**：可走点（青绿 `0x6fd6a8`）与可吃点（红 `0xff4d3d`）是典型红绿对，但**几何形状不同**——小实心盘 vs 大空心环，尺寸差 2 倍以上。红绿色盲下仍可靠形状与大小区分。阻挡点用灰色叉形，第三形状。
- **红黑双方**：除色相外还有明度差（`#d8483a` L≈0.20 vs `#1c1f26` L≈0.01）、底座汉字标识、暖/冷配件金属色三重编码，不依赖单一色觉通道。
- **文字对比度（对 `--panel-bg` 面板底）**：`--text #e8e3d6` ≈ 14:1 ✓ · `--text-dim #9a958a` ≈ 6.4:1 ✓ · `--liu-jin #c9a227` ≈ 7.9:1 ✓ · `--check #ff2b1d` ≈ 5.1:1 ✓ —— 均过 WCAG AA（4.5:1）。
- **字面可读性兜底**：底座顶面汉字自带 `emissiveMap`（0.28），暗部不失读；场景背景/雾色刻意较 `PALETTE.bg` 提亮一档（`0x1a2230` / `0x232b38`），避免玄黑棋子剪影糊进纯黑背景。
- **不依赖颜色的状态播报**：将军同时有横幅文字「将 军 ！」、音效、震屏、红光四通道。
- **性能可访问性**：帧率低于 40fps 自动降像素比并关阴影，并 toast 告知用户。

**缺口（记录，待 team-lead 排期，本文不擅自改代码）**

- **触控目标偏小**：`.btn` 高 34px / min-width 34px，`@media` 窄屏进一步降到 30px，低于 44×44 CSS px 的推荐值。
- **禁用了缩放**：`<meta viewport>` 含 `maximum-scale=1.0, user-scalable=no`，低视力用户无法双指放大。
- **两处对比度未达 AA**：`--text-faint #6b6760` ≈ 3.4:1（用于 `.captured-none` / `.move-log-empty` 等弱化文本）；`--side-red #d8483a` ≈ 4.47:1，卡在 4.5 线下。
- **未提供的可访问性开关**：色盲模式（提示色替换）、字体缩放、键位重映射、减弱动效（`prefers-reduced-motion` 未被 respect，震屏/粒子无法关闭）、字幕/文本替代。
- **键盘可达性**：控制栏为原生 `<button>`/`<select>`，可 Tab；但 3D 棋盘本身仅支持指针拾取，无键盘走子路径。
