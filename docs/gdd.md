## 1. 产品定位与目标玩家

### 1.1 一句话定位
**一局你早就会下的棋，被放进你从没见过的战场。**
规则百分之百是标准中国象棋——**零学习成本**；体验百分之百是新的——**3D 秦军战阵**、程序化生成的青铜与玄铁、每一次吃子都是一次真实的冲锋。

### 1.2 差异化坐标
| 维度 | 常见象棋 App | 本作 |
|------|------------|------|
| 表现 | 2D 平面棋盘 + 圆片 | 3D 立体棋子 + 秦式战阵环境 |
| 反馈 | 一个"啪"的音效 | 分级 Juice 反馈体系（见 juice-oil-windex.md） |
| 规则可见性 | 只标合法点，错了只说"不能走" | 阻挡点叉号 + 26 条**具体原因**文案 |
| 门槛 | 需下载 / 注册 / 广告 | 打开网页即玩，无后端、无账号、无广告 |
| 体量 | 大而全（联网/排位/残局库） | 小而精（单机对弈体验的极致打磨） |

### 1.3 目标玩家（Bartle 类型分析）

| 类型 | 占比预期 | 他们要什么 | 本作如何满足 | 优先级 |
|------|:---:|-----------|------------|:---:|
| **Killer**（杀手/竞争者） | 40% | 战胜对手、压制感 | AI 三档难度、连斩反馈、吃大子的强反馈、将军的全屏压迫 | **P0** |
| **Achiever**（成就者） | 35% | 进步、掌控、正确性 | 难度阶梯、悔棋降低挫败、中文记谱可复盘、终局原因明示 | **P0** |
| **Explorer**（探索者） | 20% | 看新东西、翻来覆去研究 | **3D 秦风视觉是主要钩子**：自由旋转视角、程序化材质细节、7 种棋子各不相同的形制、开局仪式 | **P1** |
| **Socializer**（社交者） | 5% | 与人连接 | **本次基本不服务**：无后端。仅提供本地"人人对战"（同屏）+ 记谱文本可复制分享 | P3 |

**结论**：主力服务 Killer + Achiever（占 75%），**3D 秦风视觉是把 Explorer 拉进来的独有筹码**——这也是本项目美术投入的商业理由，而不只是"好看"。Socializer 明确不服务，不做联机（见 §6 Won't）。

## 2. 三条设计支柱

支柱是**决策仲裁器**：任何取舍争议，回到支柱上判。

### 支柱一：**每一枚棋子都是一个活着的秦军单位**
不是圆片上写个字，是有底座形制、有甲胄轮廓、有材质质感的**兵种**。车是战车，马是骑兵，炮是抛石机，卒是徒卒。
→ *推论*：棋子必须能在 3D 下被认出兵种（形制差异 > 文字差异）；吃子必须表现为"一个单位被摧毁"而非"一个图标消失"。

### 支柱二：**规则从不神秘，胜负从不侥幸**
玩家永远知道自己能走哪、为什么不能走、现在是什么局面。所有的困难都来自**对手**，不来自**界面**。
→ *推论*：任何"玩家因为看不懂界面而输"的情况都是 Bug 级缺陷；但"玩家因为算不过 AI 而输"是正确的设计。绝不做走法优劣提示（那会偷走胜利的含金量）。

### 支柱三：**一次点击，值回票价**
每一次输入都必须换来超出预期的反馈密度。宁可少做一个功能，也要把落子的手感做透。
→ *推论*：反馈预算优先分配给**高频动作**（选中、落子、吃子），而非低频功能（设置面板动效）。

## 3. MDA 分析

### 3.1 Mechanics（机制层）—— 完全继承，不做改动
标准中国象棋规则全集：7 种棋子行度、河界限制、九宫限制、蹩马腿、塞象眼、炮的隔子吃、白脸将禁则、自将军禁则、将死 / 困毙 / 三次同形和局。

> **设计决策**：**一条规则都不改。** 这是本作最重要的克制。
> 中国象棋的机制层经过千年调优，任何"创新"都是负收益，且会摧毁"零学习成本"这一核心优势。我们的创新空间**全部**在 Dynamics 的呈现与 Aesthetics 的扩张上。

### 3.2 Dynamics（动态层）—— 对弈博弈
玩家与 AI 在机制约束下涌现出的行为：兑子计算、控线、马炮配合、士象全的防守结构、残局的兵种价值反转。
**我们唯一介入 Dynamics 的手段是 AI 难度分档**——它决定了博弈的深度，进而决定心流曲线（见 §4.2）。

### 3.3 Aesthetics（美学层）—— 本作的主战场

用 LeBlanc 八种美学分类，标注传统象棋 vs 本作：

| 美学 | 传统 2D 象棋 | 本作 | 增量来源 |
|------|:---:|:---:|---------|
| **Challenge 挑战** | ★★★★★ | ★★★★★ | 继承（机制未改） |
| **Sensation 感官** | ★☆☆☆☆ | **★★★★☆** | **3D + Juice 体系** |
| **Fantasy 幻想** | ★☆☆☆☆ | **★★★★☆** | **秦风世界观代入** |
| Expression 表达 | ★★☆☆☆ | ★★★☆☆ | 记谱 = 玩家的棋风留痕 |
| Discovery 探索 | ★☆☆☆☆ | ★★☆☆☆ | 视角自由 + 材质细节 |
| Narrative 叙事 | ☆☆☆☆☆ | ★☆☆☆☆ | 无剧情，仅氛围 |
| Fellowship 交谊 | ★★★☆☆ | ★☆☆☆☆ | **主动放弃**（无联机） |
| Submission 消遣 | ★★★☆☆ | ★★★☆☆ | 持平 |

#### 论证：3D 秦风建模如何把 Aesthetics 从纯 Challenge 扩展到 Sensation + Fantasy

**传统象棋的美学是极度偏科的**：Challenge 满分，其余接近零。它是一个"纯智力信号"游戏——棋子是抽象符号（圆片+字），棋盘是抽象拓扑（线与点），交互是抽象操作（拿起、放下）。这种抽象性是它的优点（便携、低成本、聚焦思维），但也意味着**一旦玩家的智力投入下降（新手期算不动、疲劳期不想算），游戏就瞬间失去全部吸引力**——因为除了 Challenge，它没有第二条腿。

3D 秦风建模精确地补上这两条腿：

**(a) → Sensation 感官**
抽象符号无法承载感官。一个"车"字圆片被拿走，是**信息**；一辆秦制战车被撞碎、木屑与青铜片四散、镜头随之一震，是**体验**。
3D 提供了 2D 结构上无法提供的三个感官通道：
1. **体积感**：棋子有高度、有阴影、有遮挡关系 → 落子的"落"字第一次有了物理含义（挤压回弹只在有体积时成立）
2. **空间感**：可旋转视角 → 玩家从"俯视一张图"变成"站在战场边缘"，视角本身成为可玩内容
3. **材质感**：程序化生成的青铜氧化斑、玄铁磨痕 → 提供了在盯着棋盘思考的漫长间隙中，眼睛可以停留的地方
→ 落地方式见 `juice-oil-windex.md` §2（Juice 十条）。

**(b) → Fantasy 幻想**
抽象符号也无法承载幻想。"馬"是一个汉字；一名披甲秦骑，是一支军队里的一个兵种。
秦朝这一美术选择尤其精准，原因有三：
1. **历史契合**：中国象棋的叙事母题即楚汉相争，棋盘上就刻着"楚河漢界"。秦是这段历史的直接上游，是玩家不需要任何解释就能接入的语境——**零叙事成本的幻想**。
2. **视觉标识度强**：秦风有一套极辨识的视觉语言（黑与赤、青铜、玄鸟纹、方正肃穆的形制、兵马俑的军阵感），且**与"两军对垒"的棋局结构天然同构**。玩家看到棋盘的第一眼就理解了幻想框架。
3. **对程序化生成友好**：秦风的美是**几何的、对称的、克制的**（方正、直线、简洁纹样），而非有机的、繁复的。这与"零外部资源、Three.js 几何体程序化组合"的技术约束**方向一致**——我们不是在技术限制下勉强做秦风，而是秦风恰好是这套技术约束下能做到最好的风格。**这是本项目最关键的一次风格-技术对齐决策。**

**(c) 增量的收益是什么**
补上 Sensation + Fantasy，直接改善两个真实痛点：
- **新手留存**：新手算不过 AI，但依然能从"把一辆战车撞碎"里获得即时快感 → 熬过学习期。
- **老手疲劳**：老手不缺 Challenge，缺的是重复千局后的新鲜感 → 感官与幻想提供了 Challenge 之外的第二动机。

**(d) 风险与边界**
Sensation 有天花板，且**会侵蚀 Challenge**——若特效遮挡棋盘、震屏干扰读局、动画拖慢节奏，则伤及主美学。
→ 因此设立红线：`juice-oil-windex.md` §5（R-01 ~ R-08）。**Challenge 永远是第一美学，Sensation 是它的放大器，不是它的竞争者。**

## 4. 核心循环与心流

### 4.1 核心循环

```
        ┌──────────────────────────────────────────────┐
        │                                              │
        ▼                                              │
   ① 观察局面 ──▶ ② 选子 ──▶ ③ 评估落点 ──▶ ④ 落子 ──▶ ⑤ 反馈 ──▶ ⑥ 对手回应
   (Windex)      (Juice)     (Windex)      (Oil)     (Juice)    (Dynamics)
```

| 环节 | 玩家心理 | 主导原则 | 关键设计 | 时长预算 |
|------|---------|---------|---------|:---:|
| ① 观察局面 | "现在什么形势？" | **Windex** | 上一步标记、将军态、走子记录 | 玩家自控 |
| ② 选子 | "试试这个子" | **Juice** | 悬停预亮 + 选中光环，让"试探"本身有快感 | ~0.1s |
| ③ 评估落点 | "能走哪？走哪好？" | **Windex** | 合法落点全亮、空点/可吃点三重区分、阻挡叉号 | 玩家自控 |
| ④ 落子 | "就它了" | **Oil** | 单击直落，零确认、零拖拽 | ~0.1s |
| ⑤ 反馈 | "爽！" / "糟糕" | **Juice** | 分级反馈，吃子 > 走子，将军全屏 | ≤0.42s |
| ⑥ 对手回应 | "它会怎么应？" | Dynamics | AI 350–1500ms 思考展示，制造"它在算"的紧张 | 0.35–1.5s |

**单圈时长**：玩家决策时间（可变，新手 3–15s / 老手 1–5s）+ **系统固定开销 ≤ 1.9s**。
系统开销必须被压到玩家察觉不到——这是 Oil 的核心 KPI。

**微循环 vs 宏循环**：
- **微循环**（每步，秒级）：上表 ①–⑥，驱动力 = 即时反馈
- **宏循环**（每局，5–20 分钟）：开局仪式 → 中局互搏 → 残局收束 → 将死/被将死 → 结算 → 再来一局，驱动力 = 胜负与难度攀升

### 4.2 心流曲线（AI 难度分档如何维持心流）

心流 = **挑战难度 ≈ 玩家技能**。象棋的技能跨度极大（从"知道马走日"到"业余三段"），单一 AI 必然让一半玩家焦虑、另一半玩家无聊。

```
 挑战
  ↑                                          ╱ 焦虑区
  │                                     ╱  （AI 太强 → 弃坑）
  │        校尉 ●─────────────────╱
  │                          ╱   心 流 通 道
  │   士卒 ●───────────╱
  │                ╱
  │ 新兵 ●────╱
  │      ╱              无聊区
  │  ╱             （AI 太弱 → 弃坑）
  └──────────────────────────────────────────→ 玩家技能
```

| 档位 | 实现 | 服务对象 | 心流作用 |
|------|------|---------|---------|
| **新兵** | 随机合法走法，略偏好吃子 | 完全新手、想放松的玩家 | 提供**必然的胜利**，建立胜任感，让新手熬过规则熟悉期 |
| **士卒** | 2 层 α-β 搜索 + 基础子力评估 | 会下但不精 | **主力档位**，胜率目标 45%–55%，最接近心流中线 |
| **校尉** | 4 层 α-β + 局面评估（子力/位置/机动性） | 有基础的老手 | 提供**可及的挑战**，胜率目标 25%–40% |

**心流维持的三个手段**：
1. **难度可随时切换且立即生效**（不需重开局）→ 玩家察觉到无聊/焦虑时能**立刻**自我调节，而不是等到下一局（那时他可能已经关掉页面了）
2. **悔棋无限次**→ 把"一步失误导致的必败"这一心流最大杀手，转化为可学习的过程
3. **难度用具象名称而非数字**（新兵/士卒/校尉）→ 降低"我选了 1 级 = 我很菜"的自我评判，鼓励玩家在正确的档位上停留

**反心流风险（需监控）**：
- 校尉档若响应超过 1.5s，思考等待会打断心流 → 硬性超时兜底（见 `juice-oil-windex.md` F-11）
- 新兵档若"随机"到一步妙手，会让新手困惑 → 可接受，不做修正（保留一点不可预测性）

## 5. 自我决定论（SDT）落地

SDT 认为内在动机来自三种基本心理需求的满足。逐条对照本作：

### 5.1 自主（Autonomy）—— "这局棋按我的方式来"
| 落地点 | 说明 |
|--------|------|
| **视角完全自由** | 旋转 / 缩放不设限（除防迷路的仰角与距离夹紧），玩家决定从哪个角度看战场 |
| **难度随时切换，立即生效** | 不锁在开局选择里 |
| **音效独立开关 + 音量连续调节** | 静音下棋是完全一等的玩法（故有 Windex 的视觉冗余，见 R-07） |
| **动效强度可控** | 减弱动效为三态：跟随系统 / 强制开 / 强制关 |
| **引导可跳过** | 首玩引导 3 步内且随时可关，不强制 |
| **所有偏好被记住** | localStorage 持久化 → 玩家的选择"算数"，这是自主感的关键（见 F-08） |

### 5.2 胜任（Competence）—— "我在变强，而不是在挨打"
| 落地点 | 说明 |
|--------|------|
| **三档 AI 阶梯** | 玩家能在自己的水平上获胜，也能看到向上的路 |
| **悔棋降低挫败** | 无限悔棋 + **人机模式退两步**（退一步等于白送 AI 主动权，反而更挫败，见 F-04） |
| **失败不羞辱** | 失败序列无嘲讽、无庆祝、镜头克制（J-09）；结算文案陈述事实而非评判 |
| **非法走法给原因而非否定** | "马腿被别住了"（教你规则）vs "不能这么走"（否定你）——26 条文案的设计初衷正在于此 |
| **将军状态持续可见** | 让玩家有机会自己解围，而不是莫名其妙被将死 |

### 5.3 关联（Relatedness）—— 弱需求，最小满足
无后端，这是本作最弱的一环，**明确只做最小闭环**：
| 落地点 | 说明 |
|--------|------|
| **中文记谱可复盘** | 右侧记录区是玩家这局棋的"文本副本" |
| **记谱一键复制** | 复制为纯文本（`1. 炮二平五  马8进7` …），可粘贴到任意聊天软件与人讨论 |
| **本地人人对战** | 同屏两人对弈，是本作唯一的真实社交场景 |
| **文化关联** | 秦风 + 楚河汉界 + 中文记谱，玩家与**文化共同体**产生连接（这是无后端条件下最划算的关联感来源） |

## 7. 已知设计风险与取舍

| 风险 | 等级 | 说明 | 缓解 |
|------|:---:|------|------|
| **3D 视角伤害读局效率** | **高** | 象棋依赖对全盘拓扑的快速扫描，斜视角下距离判断变难，老手会觉得"不如 2D 好使" | ① 默认机位必须接近俯视（建议仰角 ~55°–60°）② 提供一键复位 ③ 建议追加"准俯视"预设视角 |
| **特效遮挡棋盘** | 中 | 粒子与全屏脉冲可能盖住关键格 | R-02 / R-04 红线；粒子生命周期 ≤700ms；全屏层 opacity ≤0.45 |
| **Juice 脱敏** | 中 | 反馈不分级会让将军变得廉价 | 强度总表 + R-04（5 级事件仅 2 个源） |
| **AI 校尉档卡顿** | 中 | 单线程 4 层搜索可能超 1.5s | 迭代加深 + 硬超时返回当前最优；必要时降为 3 层 |
| **秦风与"楚河汉界"的历史错位** | 低 | 严格说秦代无楚汉之争 | 定位为**风格化战阵**而非历史复原；棋盘保留标准刻字（Windex 优先于考据） |
| **零构建 + CDN 依赖网络** | 中 | CDN 不可达则全盘失败 | 加载超时 5s → 明确错误页 + 重试（见 `ux-spec.md` §6） |
