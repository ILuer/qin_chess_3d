## 四、缺陷清单

### S1 阻塞（0 项）
无。

### S2 严重（0 项）
无。

### S3 一般（3 项）

| ID | 描述 | 影响 | 建议 |
|----|------|------|------|
| G1 | **灯光参数未采用美术预设** | scene.js 自定义灯光（白色环境光 0.16 vs 美术预设冷蓝 0x2b3444 @ 0.55），材质 roughness/metalness 是按预设调的，当前灯光可能导致暗部偏平 | 后续收敛到 `boardMesh.js` 导出的 `LIGHT_PRESET` |
| G2 | **PALETTE 双定义** | constants.js（工程用特效色）和 materials.js（美术用材质色）各一份，键名体系不同但职责分离，当前不自洽也不冲突 | 收敛为单一真相源或明确注释分工 |
| G3 | **悔棋/重开为瞬时重建** | 未使用 animator 的 dissolve/restore 平滑回退，功能可用但视觉不够华丽 | 后续迭代 |

### S4 轻微（2 项）

| ID | 描述 |
|----|------|

| L2 | 项目根目录残留成员临时验证文件（_t.mjs 等），不影响运行 |
