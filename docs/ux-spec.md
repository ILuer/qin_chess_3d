### 1.3 浮层层级（z-index）

| z | 层 | 命中鼠标 | 说明 |
|:-:|----|:---:|------|
| 0 | WebGL canvas | ✅ | 3D 视口 |
| 10 | HUD / 侧栏 / 状态条（DOM） | ✅ | 常驻界面 |
| 20 | Toast | ❌ | 不阻挡点击，2.0s 自动消失，不堆叠 |
| 30 | 首玩引导气泡 | ✅（仅气泡本体） | 可跳过 |
| 40 | 全屏脉冲 / 将军字幕 / 去饱和 | ❌ `pointer-events:none` | 见 J-06 / J-09 |
| 50 | 模态：确认框 / 结算浮层 | ✅ + 背景遮罩 | 仅 3 处（重开 / 切模式 / 结算） |
| 60 | 加载遮罩 / 致命错误页 | ✅ | 见 §6 |

### 1.4 响应式与最小尺寸

| 视口宽 | 处理 |
|--------|------|
| ≥ 1200px | 完整三栏布局（上表） |
| 900–1199px | 记录栏收窄至 200px；HUD 按钮只留图标 + `title` |
| < 900px | 记录栏折叠为**右侧抽屉**（HUD 图标唤出），3D 视口占满 |
| < 640px 或 高 < 480px | 显示提示条："建议在更大的窗口中对弈"（不阻断，仍可玩） |

> 竖屏移动端重排 = **Won't**（GDD W-05）。触控事件兼容做（F-15），布局不专门适配。

## 2. 交互状态机

### 2.1 状态定义

| 状态 | 含义 | 输入是否锁定 |
|------|------|:---:|
| `BOOT` | 加载资源 + 开局仪式播放中 | 仅接受"跳过" |
| `IDLE` | 己方回合，无选中 | 开放 |
| `HOVER` | `IDLE`/`SELECTED` 的**显示子态**（指针悬停在可动子上）。**无副作用**，不影响任何逻辑转移 | 开放 |
| `SELECTED` | 己方回合，已选中某子，落点已高亮 | 开放 |
| `ANIMATING` | 走子/吃子/悔棋动画播放中 | **锁定**（有输入缓冲，见 F-12） |
| `AI_THINKING` | AI 计算中（人机模式） | 锁定（可用 HUD 按钮） |
| `GAME_OVER` | 终局 | 走子输入全部拦截 |

**叠加标志（不是独立状态）**：
- `inCheck`：当前行棋方被将军 → 叠加视觉（C-04），**不改变任何转移规则**
- `modalOpen`：模态打开 → 拦截棋盘输入，`Esc` 关闭

### 2.2 状态转移图

```
                    ┌──────── 跳过 / 播完 ────────┐
                    │                             ▼
   [页面加载] ──▶ BOOT ─────────────────────────▶ IDLE ◀───────────┐
                                                  │  ▲             │
                              点己方可动子 ────────┘  │             │
                                     │               │ Esc /       │
                                     ▼               │ 再点该子     │
                                 SELECTED ───────────┘             │
                                     │                             │
                        点合法落点 / 可吃子                          │
                                     ▼                             │
                                ANIMATING ──── 人人模式 ────────────┤
                                     │                             │
                                     └── 人机模式 ─▶ AI_THINKING ──▶ ANIMATING ──┘
                                     
   任意状态 + 终局判定 ═══════════════════════════════════▶ GAME_OVER
   GAME_OVER + 「再来一局」 ═════════════════════════════▶ BOOT（仪式缩短版）
   任意状态 + 悔棋 ══════════════════════════════════════▶ ANIMATING ─▶ IDLE
```

### 2.4 非法落点的原因判定优先级

同一次点击可能同时命中多个非法条件，**必须按此顺序取第一个命中项**作为 toast 文案，否则玩家会收到"技术上正确但没抓住要害"的提示。

```
1. GAME_OVER            对局已结束
2. AI_THINKING          AI 思考中
3. NOT_YOUR_TURN        不在己方回合
4. NOT_YOUR_PIECE       点了对方的子（作为"起点"时）
5. OWN_PIECE            终点是己方子（仅拖拽落子路径可达）
6. SHAPE_*              走法根本不符该子行度（车走斜线等）  ← 先否定"形"
7. ELEPHANT_RIVER /     过河 / 出宫 / 兵后退 / 兵未过河横行  ← 再否定"域"
   ADVISOR_PALACE /
   KING_PALACE /
   PAWN_BACK / PAWN_SIDE
8. HORSE_LEG /          蹩马腿 / 塞象眼                    ← 再否定"路"
   ELEPHANT_EYE
9. PATH_BLOCKED /       直线阻隔 / 炮无架 / 炮越子
   CANNON_NO_MOUNT /
   CANNON_JUMP
10. FLYING_KING         白脸将
11. MUST_RESOLVE_CHECK  正被将军且此步不解将          ← 最后判"局"
12. SELF_CHECK          此步导致己方被将
13. GENERIC             兜底（不应出现，出现即 Bug）
```

**设计理由**：玩家的心智是**形 → 域 → 路 → 局**由浅入深的。若一步同时"车走斜线"且"会自将军"，告诉他"会自将军"是无用信息——他根本还没走对形。**先纠正最基础的误解。**

**验收**：
- □ 每一条转移表单元格实测行为一致
- □ 优先级 1–12 每条都能被构造出触发场景，且文案正确
- □ `GENERIC` 在完整对局测试中触发次数 = **0**

## 3. 首次游玩引导（3 步内）

**触发条件**：`localStorage['qin3d.onboarded']` 未设置。
**通用规则**：气泡出现在**棋盘外侧空白区**，绝不遮挡棋盘；右上角常驻「跳过引导」；任一步完成即自动进入下一步；引导期间**不禁用任何操作**（不是强制教程，只是提示）。

| 步 | 触发时机 | 气泡文案 | 视觉指引 | 完成条件 |
|:-:|---------|---------|---------|---------|
| **1** | 开局仪式结束后 400ms | **点击你的棋子**<br><sub>你执红，红方先行</sub> | 红方全体棋子轻微呼吸脉冲 1.5s；箭头指向红炮 | 玩家选中任意己方子 |
| **2** | 进入 `SELECTED` 后立即 | **亮点可落，红环可吃**<br><sub>灰色叉号 = 此路不通</sub> | 气泡带两个图例小图（青白点 / 红环） | 玩家完成第一次落子 |
| **3** | 玩家第一步动画结束后 | **`U` 悔棋　`R` 复位视角**<br><sub>右侧记录你的每一步</sub> | 高亮 HUD 悔棋/视角按钮 + 记录栏首条 | 点「知道了」或 3.5s 后自动消失 |

- 完成第 3 步或点跳过 → 写入 `qin3d.onboarded = '1'`，**永不再现**
- 帮助面板（`?`）内提供「重看引导」入口，供玩家主动召回

**验收**：
- □ 三步全程 ≤ 3 次玩家动作，无一步需要"阅读后点确定"
- □ 气泡任何时候都不遮挡 3D 棋盘区域
- □ 引导期间玩家可正常自由操作（旋转视角、开设置都不打断）
- □ 二次访问不再出现

## 5. 无障碍（Accessibility）

### 5.1 色觉友好 —— **红黑区分绝不能只靠色相**

红绿色盲（约 8% 男性）在红 vs 黑上问题不大，但**低对比度屏幕、暗环境、红色弱（Protanomaly）**下的红色会显著变暗、趋近黑色。因此采用**四重冗余编码**：

| 维度 | 红方 | 黑方 | 冗余强度 |
|------|------|------|:---:|
| **明度（关键）** | 暖铜色，L\* ≈ 62 | 冷玄铁，L\* ≈ 32 | **ΔL\* ≥ 25**，灰度下即可区分 |
| **底座形制** | 圆形底座 | 八角形底座 | 纯形状，色觉无关 |
| **刻字工艺** | 阳文（凸字 + 高光） | 阴文（凹字 + 阴影） | 纯光影 |
| **文字标签** | 记录栏前缀「红」 | 前缀「黑」 | 纯文本 |

**落点标记同理**（C-01）：空点 = 青白**实心圆点** `r=0.16`；可吃点 = 红色**带刺圆环** `r=0.40`。**形状 + 尺寸 + 颜色**三重区分。

**验收**：
- □ 全局截图转灰度后，红黑双方与两类落点标记仍全部可区分
- □ Protanopia / Deuteranopia / Tritanopia 三种模拟下可区分
- □ 所有文字对背景对比度 ≥ 4.5:1（HUD 关键信息 ≥ 7:1）

### 5.2 键盘可达性

**必做（MVP）**：
- 所有 HUD 按钮、下拉、滑块可 `Tab` 到达，焦点环清晰可见（2px 描边，不可用 `outline:none` 消除）
- 模态内焦点被捕获（focus trap），`Esc` 关闭，关闭后焦点返回触发元素
- 结算浮层打开时主按钮「再来一局」自动获得焦点

**建议做（Could，GDD C-05）**：
- 方向键在棋盘上移动**焦点格**（黄色方框指示），`Enter` = 选中/落子，`Esc` = 取消
- `aria-live="polite"` 区域播报焦点格与走子结果：「红马，二路」「红方 炮二平五」「黑方被将军」

### 5.3 动效减弱（`prefers-reduced-motion`）

三态开关（设置面板）：**跟随系统 / 强制开启动效 / 强制减弱**，持久化到 `qin3d.reducedMotion`。

减弱模式下（对应红线 R-06）：
| 项 | 处理 |
|----|------|
| 镜头震动 | **归零**（全部级别） |
| 粒子数 | **×0.3** |
| 位移/回弹动画 | **保留但时长 ×0.6** —— 不可全禁：棋子瞬移会让玩家看不清"从哪到哪"，反伤 Windex |
| 全屏红脉冲 | 改为**静态红边框显示 1.2s**，无闪烁 |
| 呼吸/脉冲循环（选中光环、将军主帅） | 改为**静态高亮**，保留可见性 |
| 开局仪式 | 缩短为 0.5s 淡入 |

**验收**：
- □ 系统开启减少动效时，首次进入即为减弱态（不需手动设置）
- □ 减弱态下仍能清楚看出每一步棋从哪走到哪
- □ 全局无 ≥3Hz 的闪烁（R-05，光敏性癫痫安全）

### 5.4 其他

- 最小字号 13px；HUD 关键信息（行棋方、将军标签）≥ 15px
- 点击目标最小 32×32px（HUD 按钮 40×40px）
- 棋子的 3D 拾取判定使用**包围盒略放大 10%**，降低精确点击压力
- 不依赖悬停传达关键信息（悬停只做增强；tooltip 的内容在别处也能获得）

## 6. 错误与边界情况的 UX

**总原则**：**绝不白屏，绝不静默失败，永远给下一步动作。**

| 场景 | 检测方式 | 玩家看到什么 | 可采取的动作 |
|------|---------|------------|------------|
| **WebGL 不支持 / 被禁用** | 创建 `WebGLRenderer` 前探测 `canvas.getContext('webgl2'\|'webgl')` | **全屏降级页**（秦风纯 CSS 背景，非白屏）：<br>「**你的浏览器暂不支持 3D 渲染**<br>请使用较新版 Chrome / Edge / Firefox / Safari，<br>并在浏览器设置中开启『硬件加速』。」 | 「查看解决方法」展开三条具体指引 |
| **Three.js CDN 加载失败/超时** | importmap 模块加载 **5s** 超时 | 遮罩内：「**资源加载失败**<br>请检查网络连接后重试。」 | 「重试」按钮（重新加载页面） |
| **加载耗时较长（>1.5s）** | 加载进度回调 | 进度文案分阶段：「铸造棋盘…」→「铸造棋子 12/32」→「调音…」 | 无（但**不得白屏**，F-07） |
| **WebAudio 被自动播放策略阻止** | `AudioContext.state === 'suspended'` | 音量图标旁出现小徽标「**点击开启声音**」，**不弹窗**、不阻断 | 点击任意处即恢复 |
| **音频合成失败**（罕见） | try/catch 包裹 SFX init | 静默降级为静音态；HUD 音量图标置灰 + `title`「本设备音频不可用」 | 无（游戏完全可玩，Windex 视觉冗余保证不漏信息） |
| **性能不足** | 连续 3s 平均 < 40fps | **自动三级降级**：① 关阴影 → ② 粒子 ×0.5 → ③ 关抗锯齿。<br>每级降级右下角 3s toast：「已自动降低画质以保持流畅（可在设置中恢复）」 | 设置面板可手动锁定「高画质」 |
| **性能恢复** | 连续 10s > 55fps | **不自动升回**（来回横跳比低画质更难受）；仅在设置面板提示「可尝试恢复高画质」 | 手动恢复 |
| **`localStorage` 不可用**（隐私模式/策略） | try/catch 探测写入 | **静默降级**为内存存储，游戏正常运行；仅在设置面板底部小字：「当前无法保存偏好设置」 | 无 |
| **AI 计算超时**（>1500ms） | 迭代加深计时器 | 无任何错误提示，直接返回当前深度最优解 —— **玩家不应感知到这是"降级"** | 无 |
| **窗口尺寸剧变 / 全屏切换** | `resize` 防抖 150ms | 平滑 resize，相机 aspect 更新，**不重置视角、不中断动画** | 无 |
| **页面隐藏（切标签页）** | `visibilitychange` | 暂停渲染循环（省电），**保留全部状态**；AI 计算继续；返回时立即恢复 | 无 |
| **无操作长时间挂机**（>5min） | 计时器 | 降帧至 30fps 省电，无任何提示；任意输入立即恢复 | 无 |
| **规则引擎抛出异常**（不应发生） | 全局 `error` 捕获 | 顶部红条：「出现异常，本步已撤销」并回滚到上一合法状态；控制台打印详情 | 继续对局 / 手动新局 |

**验收**：
- □ 强制禁用 WebGL 后打开页面，看到的是降级页而非白屏或报错
- □ 断网后打开页面，5s 内出现明确的加载失败提示与重试按钮
- □ 首屏无浏览器 autoplay 警告
- □ 隐私模式下游戏完整可玩
- □ 任意错误场景下，玩家都能看到"接下来能做什么"
